# DiPartners.io — Design Request MVP

Landing/formulario para recibir requerimientos de diseño.

## Publicación
El sitio se publica como contenido estático en Vercel.

## Conectar Google Sheets
1. Crea una hoja nueva en Google Sheets.
2. Extensiones → Apps Script.
3. Pega el contenido de Code.gs.
4. Implementa como Aplicación web, ejecutando como tú y permitiendo acceso a cualquier persona con el enlace.
5. Copia la URL /exec.
6. Reemplaza PEGA_AQUI_TU_URL_DE_APPS_SCRIPT en index.html y vuelve a desplegar.

## Evolución
Después podemos sustituir Google Sheets por Supabase y crear un dashboard interno con estados, responsables, fechas y archivos.
